# 🟩 One Million Checkboxes in React!?!?!

I’m sure you’ve heard of the legendary
👉 [**One Million Checkboxes**](https://onemillioncheckboxes.com/)

This little experiment is inspired by that project (and by some stuff I’ve worked on at my job).
I wanted to see just **how far I could push React** — and honestly, it did _not_ disappoint!

---

## ⚙️ What’s Going On Here?

This project renders **one million checkboxes** using React.
The biggest bottleneck turned out to be the **browser itself**, not React!
There’s still a funny little bug where, if you don’t zoom out far enough,
the browser fails to render all the elements (at least on my machine 🫠).

---

## 🚀 Performance Notes

React + JavaScript = surprisingly efficient combo.
If I had more complex data or interactions, I’d expect some slowdowns —
but for this setup, it’s smooth sailing.

Seriously, I was expecting my laptop to take off. Instead, it just shrugged. 💪

---

## 🔮 What’s Next?

For my next “how far can I push it” project,
I’m planning **one million inputs** —
where the client can control both the input type (checkbox, date, text, etc.)
_and_ the data that goes into it.

I’ll probably need to go beyond simple virtualization for that one…
but knowing React, I’ll probably be surprised again by how well it handles it 😅

---

## 🧠 Final Thoughts

Don’t take this project too seriously — it’s more of a
“because I can” experiment than something you’d actually ship to production.

But hey, if your browser survives opening it...
maybe React really _can_ handle one million of anything. 😎
